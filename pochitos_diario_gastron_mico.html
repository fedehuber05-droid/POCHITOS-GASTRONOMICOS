Manual de Implementación y Guía Técnica

Esta sección detalla la arquitectura, el código SQL, la configuración de sincronización para ambos usuarios y las pruebas de funcionamiento de Pochitos.

A. Arquitectura Elegida

Pochitos está construido con una arquitectura Jamstack moderna utilizando HTML5 semántico, Tailwind CSS y JavaScript vainilla modular de alto rendimiento. Para la persistencia y sincronización entre Lara y vos sin necesidad de servidores complejos, se integra directamente con Supabase (PostgreSQL + Realtime WebSocket), permitiendo que cualquier cambio en un dispositivo se refleje de inmediato en el otro.

B. Esquema de Base de Datos (SQL para Supabase)

Ejecutá el siguiente script SQL en el panel SQL Editor de tu proyecto en Supabase:

create table public.restaurants (
    id uuid default gen_random_uuid() primary key,
    name text not null,
    category text not null,
    address text,
    maps_url text,
    visit_date date not null,
    food_consumed text,
    comments text,
    photo_url text,
    total_cost numeric(12,2) not null default 0,
    currency text default 'ARS',
    people_count integer default 2,
    rating_lara numeric(2,1),
    rating_me numeric(2,1),
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Habilitar Row Level Security (RLS)
alter table public.restaurants enable row level security;

-- Política de acceso abierto para usuarios autenticados o con clave anon permitida
create policy "Permitir acceso total a Pochitos" on public.restaurants
    for all using (true) with check (true);

-- Habilitar Realtime para la tabla
alter publication supabase_realtime add table public.restaurants;

C. Guía de Instalación Local y Publicación Online

  1. Crear proyecto en Supabase: Ir a supabase.com, crear un proyecto gratuito y ejecutar el script SQL anterior.
  2. Obtener credenciales: Copiar la Project URL y la anon public key desde las configuraciones del proyecto (API).
  3. Ejecutar localmente: Guardar el código en un archivo llamado index.html, abrirlo en tu navegador y configurar las credenciales haciendo clic en el ícono de base de datos en la esquina superior derecha.
  4. Publicación en Vercel, Netlify o GitHub Pages: Subí el archivo index.html a un repositorio de GitHub y conectalo con Netlify o Vercel con un solo clic. ¡Tendrás una URL permanente lista para compartir con Lara!

D. Pruebas de Funcionamiento Recomendadas

  • ✅ Agregar un restaurante con gasto de $ 35.000,00 y verificar el formato argentino.
  • ✅ Calificar con 4.5 estrellas de Lara y 4.0 estrellas propias, comprobando que el promedio se calcule automáticamente como 4,3 estrellas.
  • ✅ Abrir la aplicación desde el celular de Lara (o ventana de incógnito) y verificar la persistencia y actualización en tiempo real.
  • ✅ Probar los filtros por categoría y ordenamientos por gasto y puntuación.
